!
Plain HTTP is not encrypted.

On a public HTTP connection, people on the network path can read your password and session. Use localhost or an SSH tunnel when possible.

Set a panel password

On an online-mode server, an operator can get the one-time code with /nab. Otherwise run nab setup in the server console. Enter that code below, then choose a password with at least 12 characters.

Sign in

Use the password you created during setup.

For access from another computer, use an SSH tunnel or explicitly configure public HTTP from the server. Public HTTP does not encrypt traffic.
